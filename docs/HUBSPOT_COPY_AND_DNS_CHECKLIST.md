## A9. FAQ (paste as HubSpot FAQ module or H3 + paragraphs)

### Who is this calculator for?
```
Independent insurance agents, agency principals, and producers exploring multi-line growth — whether you write primarily Medicare, ACA, life, annuity, ancillary, or a mix. It is not a consumer quoting tool.
```

### Do I need to log in or connect my CRM?
```
No. There is no login, no AgentSync requirement, and no CRM write-back. Use approximate practice numbers only.
```

### Will this upload my client list?
```
No. Do not enter client names, member IDs, or PHI. The tool is designed for practice-level estimates only.
```

### Are the dollar amounts guaranteed?
```
No. All figures are illustrative estimates based on assumptions you can inspect in the tool. Actual compensation depends on contracts, carrier schedules, production, persistency, and suitability. PSM does not guarantee income or sales results.
```

### Why show a range instead of one number?
```
A single number implies false precision. We show a conservative-to-high range and a planning estimate so you can discuss opportunity credibly with your team or with PSM.
```

### What products can appear as opportunity?
```
Complementary lines outside your selected primary markets — including Medicare-focused and other PSM-supported lines such as ACA, life, and ancillary offerings, depending on your inputs. Annuity may be used as a primary market focus; opportunity sizing follows the product rules in the calculator.
```

### How is the multi-year path different from Year-1?
```
Year-1 focuses on near-term impact from placing complementary products on your eligible book and new clients. The multi-year path illustrates how new production and renewals on retained book may compound over time under stated persistency and place-rate assumptions.
```

### What happens when I request a portfolio review?
```
You can submit contact details (and NPN or mark NPN pending) so a PSM teammate can follow up about contracting and multi-line support. That form is for licensed professionals and agency principals — not for submitting consumer applications.
```

### Is this a substitute for carrier training or suitability?
```
No. Always follow carrier guidelines, state rules, and suitability standards. This tool does not provide compliance, tax, or legal advice.
```

### Why PSM?
```
PSM helps independent agents expand what they can offer clients — with contracting paths, training, and distribution support across multiple product lines. Use the calculator to frame the opportunity; use PSM to operationalize it.
```

## B3. DNS (at your DNS host — Cloudflare, GoDaddy, Route53, etc.)

| Step | Action | Done |
|---|---|---|
| 1 | Log in to DNS for `psmbrokerage.com` | ☐ |
| 2 | Add record: **Type CNAME** | ☐ |
| 3 | **Name/host:** `calculator` (or full `calculator.psmbrokerage.com` if your host requires FQDN) | ☐ |
| 4 | **Target/value:** exactly what Vercel shows (often `cname.vercel-dns.com`) | ☐ |
| 5 | Proxy status: if Cloudflare, follow Vercel guidance (often DNS-only / grey cloud for clean certs) | ☐ |
| 6 | TTL: Auto or 300–3600 | ☐ |
| 7 | Save | ☐ |

**Apex note:** This checklist is for a **subdomain** (recommended). Root domain `@` is harder; don’t use apex unless IT prefers A/ALIAS records per Vercel docs.

## B5. App environment variables (Vercel → Production)

Set or update, then **Redeploy**:

| Variable | Suggested value | Done |
|---|---|---|
| `VITE_PUBLIC_SITE_URL` | `https://calculator.psmbrokerage.com` **or** keep HubSpot campaign URL if that’s the public campaign link — see note below | ☐ |
| `VITE_PUBLIC_APP_URL` | `https://calculator.psmbrokerage.com` | ☐ |
| `LEAD_WEBHOOK_URL` | (existing HubSpot/Zapier webhook — unchanged) | ☐ |
| `LEAD_ALLOWED_ORIGINS` | Include `https://calculator.psmbrokerage.com` and `https://www.psmbrokerage.com` if not already covered | ☐ |
| `VITE_AUTH_ENABLED` | `false` (public tool) | ☐ |

**Note on `VITE_PUBLIC_SITE_URL`:**  
- If HubSpot remains the **campaign** URL for eblasts, you may keep canonical/marketing URL as the HubSpot page and still run the app on the subdomain.  
- If the subdomain becomes the **primary** public tool link, set site URL to the subdomain and update HubSpot CTAs.

After env changes: **Deployments → Redeploy** (Vite bakes `VITE_*` at build time).
